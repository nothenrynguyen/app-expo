## Correct route and current assessment

[CareerOneStop's current Jobs API notice](https://cloudfront.careeronestop.org/Developers/WebAPI/jobs-api-updates.aspx) directs new job API requests to NLx. The old general registration and free-service terms do not establish current NLx job-feed permission or pricing.

[NLx's current access page](https://nlxresearchhub.org/data-access) describes a licensing transition, limited current authorized uses, and possible referral of free public job boards to another access route. Its standard research conditions prohibit sharing identifiable individual job records publicly. Those conditions do not fit empluzzed's public listings and committed snapshots. **Do not accept the standard research acknowledgment as though it authorizes this board.** Request explicit public-feed permission or a referral first. Zero-cost eligibility remains unconfirmed.

## Project summary, for the 800-character field

empluzzed (https://empluzzed.fyi) is a free, account-free early-career job board. We seek an authorized, zero-cost public NLx job feed for nationwide U.S. internships and graduate roles across business, finance, operations, engineering and IT. We would display selected job metadata and application links, add eligibility filters and duplicate handling, and remove unavailable listings. Our static site serves public JSON snapshots committed to a public GitHub repository. We need explicit permission for identifiable public job listings and these snapshots, or referral to the appropriate public-feed program. This is not a request to publish restricted research microdata. No resumes, personal matching or model training are involved.

## Additional field-ready descriptions

Purpose: Help early-career applicants find relevant paid roles across occupations without accounts, fees, staffing-agency clutter or repeated destinations. This extends an existing public service rather than creating a research dataset for resale.

Methodology: Use a bounded scheduled importer, preserving supplied factual content and approved source attribution. Apply transparent country, career-level, employer-quality, availability and duplicate checks. Add separate derived category tags. Do not claim every returned job is eligible. Provider approval must cover filtering, normalized display, public static snapshots and source retention/removal rules before implementation.

Data requested: Current active job postings nationwide in the United States, with employer display name, title, location, posting/closing dates, public description or excerpt if licensed, stable job ID and application/source URL. No FEIN, private employer address, applicant information, resumes, historical microdata, geocoding data or model-training rights are requested. Request optional occupational codes only if permitted and useful.

Dissemination: Selected identifiable job records would be visible to anyone at empluzzed.fyi and in its public repository, without registration or payment. This requires an expressly authorized public-feed arrangement. We cannot promise research-only restricted storage while running that architecture.

Access: Prefer a read-only API. Keys would be kept in private automation secrets. No third party should receive raw restricted data, including AI tools, without express authorization. AI-assisted software development is separate from production processing, which currently uses deterministic rules rather than model inference. The owner must accurately disclose any intended vendor access if the form asks.

Owner confirmation required: applicant identity/affiliation; authorized users or vendors; funding status; any institutional/IRB requirements; and the legal signatory. Do not invent a university sponsor, faculty member or legal nonprofit status.
