# Solutions and support role audit

This audit uses the published snapshots generated on September 27, 2026. It defines the high-precision boundary for the **Solutions / Support** category without confusing it with Product Management, product design, or general product engineering.

## Current coverage

- Full-time: 20 listings have an explicit support title.
- Full-time: 34 additional listings use Solutions Engineer, Applications Engineer, Forward Deployed, Sales Engineer, or related customer-facing titles.
- Internships: 4 listings have an explicit support title.
- Internships: 15 additional listings use Solutions Engineer, Applications Engineer, Forward Deployed, Sales Engineer, or related customer-facing titles.

After applying the conservative rules below, the refreshed snapshot contains 54 full-time listings and 19 internship listings. This increase came from evaluating experience requirements and customer-facing context already present in Greenhouse, Lever, and Ashby descriptions, plus a small set of reviewed official boards. These counts will change naturally as the hourly snapshots change.

## Include

High-confidence titles:

- Product Support Engineer or Product Support Specialist
- Technical Support Engineer, Specialist, or Analyst
- Software Support Engineer or Software Support Specialist
- Application Support Engineer
- Customer Support Engineer
- Support Engineer when the title begins with that role name
- Solutions Engineer or Solutions Engineering
- Implementation Engineer
- Customer Engineer
- Field Applications Engineer
- Sales Engineer
- Deployment Engineer
- Forward Deployed Engineer
- Technical Account Manager when the broader early-career rules accept it

## Keep in multiple categories

The new tag is additive. It does not remove a role from an existing technical category.

- Software Support Engineer: Software, Solutions / Support, and IT / Security
- Forward Deployed Software Engineer: Software and Solutions / Support
- Technical Support Engineer: Solutions / Support and IT / Security
- Field Applications Engineer: Solutions / Support, plus a physical engineering tag only when the title supplies that context
- Applications Engineer: Solutions / Support only when the source description confirms direct customer, client, field, or pre/post-sales work

## Exclude

- Product Manager, Product Owner, and Product Management roles
- Product Designer and UX/UI roles
- Generic Product Engineer roles
- Production Support Engineer, which usually describes internal production operations
- Generic Integration Engineer, which is commonly systems, test, vehicle, or manufacturing integration
- Generic Applications Engineer when the description only describes internal systems, data, or process work
- Help desk, desktop support, and generic IT support without a customer-facing engineering signal
- Customer Success Manager and nontechnical customer service roles

## Known limitation

Public job records do not retain descriptions, so ambiguous Applications Engineer titles stay excluded unless the ingestion source provides customer-facing context. Greenhouse, Lever, and Ashby descriptions are evaluated during ingestion, and the accepted role tags are stored with the published job.
